# grill-me（DSH 适配版）

一个"逐题拷问"技能：对你的方案、规格或工单**一次只问一个问题**（每题 2–4 个具体选项、有证据才给推荐答案），把每个确认的答案**先落盘再问下一题**，结束时给出**五维歧义报告 + 阈值门**。

目标只有一句话：**产出一个"零上下文的人照着就能干、不用再问你"的东西。**

- 版本：**v1.7.0-dsh**（运行副本 `SKILL.md`，见 `CHANGELOG.md`）
- 运行环境：**DeepSeek Harness**（不是 Claude Code），使用 `ask_user_question` / `read` / `write` / `edit` 四类工具；宿主不提供目录枚举（Glob），故技能内的路径预检不依赖它
- 许可：**MIT**（你的新增部分，见 `LICENSE`）；基座 [`max4c/skills`](https://github.com/max4c/skills) 的 MIT 与版权声明见 `THIRD-PARTY-NOTICES.md` 与 `SKILL.md` 末尾

## 装法

把 `grill-me/` 整个目录放进你的技能目录：

```
<DSH 家目录>/skills/grill-me/SKILL.md      ← 必需（运行副本）
<DSH 家目录>/skills/grill-me/README.md     ← 可选，给人看
```

Windows 上默认是 `C:\Users\<你>\.dsh\skills\grill-me\`。放好后**重开会话**（技能清单在会话建立时定版），清单里出现 `grill-me` 即可用。

## 用法

直接说，任一触发词都行：

- 「**grill me**：<把你的方案粘进来>」
- 「拷问我这个方案 / 把这方案问穿 / 我有漏吗 / 风险在哪」

它会：

1. **首题之前**先声明 checkpoint、备份、账目三者的路径与写入范围（位置没约定时会先问你）；
2. 一次问一个问题，每题给 2–4 个具体选项；**有证据支持某偏好时**才给推荐答案，否则明确写"无推荐答案"；
3. 每题确认后**一次写入**同时落下 Q&A 与恢复信息，**写之后新一次读**核验，然后才问下一题；
4. 你说「够了 / 停」→ 立即打印报告退出；结束时给五维评分与门状态。

**它会往盘上写什么**（这是它的特点，也是它的代价）：工作区下 `grill\<日期>-<主题>.md`（拷问记录）与同目录的账目文件。要"不留痕"就直接说——它会切到**无落盘模式**，只在会话内保存摘要（但**不保证跨会话恢复**）。

**评分与门**：五维（Goals / Acceptance / Boundaries / Alternatives / Assumptions）各 0–1；聚合＝五维均值；阈值 spec 0.2 / ticket 0.3 / freeform 0.4。**通过需三条同时满足**：聚合 ≤ 阈值、**任一维 ≤ 0.5**、**无阻断性 Open Question**。

## 已知限制（别当它已充分验证）

- 只做过**文本级**多轮评审（含一次上游表达比对）和**一次空转功能测试**（8 题，见 `CHANGELOG.md`）；**无落盘模式的路径尚未实测**。
- 空转测试暴露并已修掉两条：账目路径被误声明时无人拦（v1.7 改为写入前实测）、每问三次工具往返导致执行者并批跳步（v1.7 改为一次写入 + 一次核验）。
- 规则是**靠执行者自觉**的：本技能不提供锁、事务或原子写入保证。
